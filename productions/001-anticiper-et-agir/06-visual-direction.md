# Direction artistique — version préparatoire

- Durée : à communiquer par John avant production.
- Format : vertical 9:16.
- Palette : bleu profond, turquoise, or doux et lumière naturelle.
- Progression : tension → observation → surcharge → calme → clarté → action.
- Montage : plans animés, travellings, zooms subtils, panoramiques, parallax, variations de cadrage et transitions cinématographiques.
- Éviter les images statiques prolongées.
- Texte écran : uniquement les leçons synthétiques validées, dans les zones de sécurité TikTok.
- Audio : aucune piste. John ajoute lui-même la voix dans Canva.
